Cascading

What it is: you try the cheapest option first and escalate only when it isn’t confident. The cheap layers can be rules, a small local classifier, or a small LLM. The expensive model is the last resort. It’s the same idea as your Tier 1/2/3 design.

The evidence: the best-known paper is FrugalGPT (Chen, Zaharia, Zou, 2023). It reported that a cascade can match the best single model’s performance with up to 98% cost reduction, or improve accuracy by 4% at the same cost. One caveat from the authors is that it needs labeled data to train the cascade strategy, plus upfront effort to set up. That’s another reason to keep building your JSON of labeled examples. 

Read:

Paper abstract: https://arxiv.org/abs/2305.05176
Full PDF: https://arxiv.org/pdf/2305.05176

prompt caching -

the provider stores the already-processed beginning (prefix) of your prompt, so later requests with the same prefix don’t pay to reprocess it. Caching works only on the prefix, so any change near the start invalidates everything after it. Put static content (system prompt, documents, examples) before dynamic content.
